# Mapa dokumentów (czytaj tylko to, czego potrzebuje zadanie)

Zawsze: `ZASADY.md` (ładowany automatycznie) i `plan/TERAZ.md` (stan i kolejka).

Na żądanie:
- `plan/DECYZJE.md` — decyzje właściciela i wykonawcy (dopisuj tam nowe).
- `plan/BLOKADY.md` — zadania zablokowane; `plan/DO_SPRAWDZENIA_NA_TV.md` — lista testów na TV.
- `plan/lektor/GLOS_CHIRP.md` — lektor Chirp (Google Cloud TTS).
- `UPSTREAM_SOURCES.md` — pochodzenie skopiowanego kodu (repo, SHA).
- `fork-tools/uitest/README.md`, `fork-tools/devtest/README.md` — narzędzia testów; `fork-tools/build.sh` — jedyny sposób budowania.
- `plan/raporty/*.md` — raporty tematyczne (wydajność, TTS, źródła, Kicia, IPTV…); otwieraj tylko ten, którego dotyczy zadanie. `*.log`, `*.txt`, `wydajnosc-surowe/`, `plan/probki/` — surowe dane, nie czytaj.

Archiwum `plan/archiwum/` — NIE czytaj w całości, najwyżej `grep`: historia `TERAZ` (wątki 1–13), dawne `STATUS`, `HANDOFF`, `STAN`, `KONTYNUUJ`, `bloki/`, `ARCHITECT_*`, `prompty/`, `PROMPT_WYDAJNOSC`, stare wersje zasad (`zasady/`).

`README.md`, `CONTRIBUTING.md`, `PRIVACY.md`, `ACCESSIBILITY_HANDOVER.md` w katalogu głównym to pliki bazy NuvioTV — nie ruszać, nie czytać.
