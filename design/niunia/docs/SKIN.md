# Nuvio skin "Niunia" (handoff)

Source of truth: `design/nuvio.css` (tokens + components) and `design/*.dc.html` (one file per screen, 960×540 dp at 1×; full pages are taller). Treat the HTML as a visual spec, not code to ship.

## Rules
- Add this as a **second skin**, never replace the current one. The current look stays the default.
- Every visual value comes from a skin token; screens read the active skin, not hard-coded values.
- Images are used exactly as TMDB serves them (no re-encoding, resizing or SVG conversion).

## Components (class in nuvio.css → component)
- `.nav` + `.navpill`: collapsed navigation "‹ [icon] Tab" top-left (20, 28). BACK at a tab's top opens `.side`.
- `.side`: sidebar panel 180 wide, items `.side-item` 36 high; `.sel` = current tab, `.foc` = white capsule.
- `.pcard`/`.prof`: profile switcher card with 80dp avatars and a green check on the current profile.
- `.btn` (`.sec`, `.rnd` 40×40, `.sm` 34 high, `.bare`, `.on`, `.foc`), `.pill`, `.tabs`.
- `.tlogo`: title logo image, width set per use, height follows art; text `.logo` is only the fallback.
- `.meta`, `.age` (outlined box), `.fmt` (filled box), `.chipb`, `.credits`.
- `.card` landscape 160×114 · `.card.w` 205×115 · `.card.p` poster 130×195 · `.card.f` spotlight 280×350 · `.card.r` round 130. `.cap` caption with `.mini` progress; `.badge` top-left.
- **`.poster` (NPoster)**: layers bottom→top: art · `.pblur` (3 backdrop-blur layers 2/6/14px masked from 56/66/78% of height) · `.ptint` (radial gradients of `--dom` in both bottom corners + soft centre radial at 80% + linear darkening from 60%) · `.ptab` top label · `.pfoot` (logo or title, then "Genre · ★ avg").
  - Variant: poster art without title → logo from TMDB (`.plogo`), else title text (`.ptitle`). Art with printed title (TMDB poster with a language) → `.baked`: no logo, only genre · rating; blur/tint start at ~82%.
  - `--dom` = dominant colour of the lower part of the art. `--tab` = average colour of the pixels right under the label (top-centre, 50% width × 9% height of the visible crop); `--tabfg` = #111 if relative luminance > 0.22 else #fff.
  - Label rules: trending → "#n Dziś"; now playing → "W kinach"; upcoming → "Premiera d mmm"; tv on the air → "Nowy odcinek"; released ≤45 days ago → "Nowość"; year < 2000 → "Klasyka"; live channel → no text label, a red `.dot` instead; otherwise no label.
  - Rating = average of all available services on a 0–10 scale (TMDB now; IMDb/RT/Metacritic when an OMDb key exists).
- `.shelf-title` (grey; `.on` white for the row holding focus), `.rail` (gap 20), `.dots`.
- `.ep`/`.eptext` episode column; focused text block sits on `.frost`.
- Search: `.sfield`, `.seg`, `.kbd`/`.key`, `.kbd2`, `.qchip`, `.rgrid`/`.rcard`.
- Settings: `.slist`, `.srow` (`.val`, chevron), `.slabel`.
- Live TV: top row of programme cards (no title) → `.ch`, `.cell` (`.now`, `.foc`), `.day`, now-line in `--live`.
- Player: progress `.prog`, `.glass` side panel with `.row`.
- **Player IPTV** (`PlayerLive`, `PlayerLiveGroup`): time range, meta (age · S E · episode title), **programme logo instead of the title when available**, source order: TVDB → TMDB → epg.ovh (custom EPG) → the channel playlist (M3U `tvg-logo` / programme entry), text title only as fallback; progress bar in `--live` up to now + red LIVE marker; channel block with ▲/▼ (channel up/down) and the **channel logo from epg.ovh** — use the existing `fork/tv/logo/ForgeChannelLogoUrl` / `ForgeLogoPack`, do not add a new source; centre pause `.btn.rnd` with label; right `+`, `i`, `⋯`. Bottom row (peeks, ▼ raises it): recurring programme → other episodes of the series (aired = green `.dot.arch`, future = badge „Wkrótce”); non-recurring → programmes from other channels in the **most specific category group, i.e. the smallest branch (leaf) of the app's existing programme category tree** (`skin/kicia/livetv/ForgeEpgCategories.programmePlace` → `Place(branch, leaf)`, rules in `ForgeCategoryRules.PROGRAMMES`). Example: a news programme sits in the leaf „Wiadomości” of the branch „Informacje i publicystyka”, so the row shows Wiadomości, Wydarzenia, Panorama, Teleexpress, not publicystyka or reportaże. Only if the leaf has no other programmes (airing now, in the archive, or coming up), fall back to the parent branch; "Inne" only as a last resort; no row when the guide gives no category. Row title = the leaf name (or the branch name after a fallback).
